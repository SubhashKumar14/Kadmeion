## Problem and motivation

Developers need a credible public showcase of projects, technical decisions and optional career-growth evidence. Many simplistic portfolio templates sacrifice individual expression; code-first platforms impose setup burden; visual editors can destroy custom code or make inaccessible output; provider-based ranking and automatic scraping may misrepresent a developer's work. Kadmeion proposes a versioned, slot-aware, content-first editor with carefully bounded source editing, private-by-default public identity and safe, exportable static releases.

## Core objective and measurable outcomes (future)

1. Produce a usable browser authoring workspace supporting five initial complete preset compositions, eight initial section layouts and Blank, with no hard catalogue ceiling.
2. Preserve modified custom source, structured content, assets and revision history under Add/Delete/Swap/Undo and export; prove with golden-file tests.
3. Publish a real SEO-ready static public portfolio from frozen revision with verified access, rollback/revocation and portable ZIP fallback under ₹0 constraints.
4. Ensure account/project/profile privacy and cross-tenant isolation through actual Supabase Auth/RLS/storage tests.
5. Demonstrate accessible keyboard-driven editing on desktop/qualifying large tablets and responsive public portfolios on phones.
6. Later provide private, opt-in analytics/DevScore/goals and permitted handle-based data connections without fabricated verification claims.

## Scope, schedule and budget

**Phase 1:** account/auth, private identity/projects, editor, static export/publishing, version control, restricted admin user/moderation. **Phase 2:** private developer metrics, goals and consented analytics. **Phase 3:** optional AI and advanced administrator dashboards. Development time is intentionally flexible, and exact completion dates require realistic execution evidence. Strict ₹0 recurring service cost; no paid APIs or hidden auto-upgrades.
