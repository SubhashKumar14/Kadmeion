# Kadmeion Glossary and Precise Terms

> **Kadmeion planning artifact · 12 November 2026 · NOT IMPLEMENTED.** `[APPROVED]` = explicit owner choice; `[PROPOSED]` = specification or architecture suggestion; `[PROOF]` = requires technical/test evidence. No code, deployment, integration, screenshots or performance claims are implied.

| Term | Definition |
|---|---|
| Account | Supabase Auth identity for a developer; does not imply a public profile. |
| Public identity hub | `/u/:handle` explicitly published developer profile with selected fields/projects. |
| Project | Developer-authored link-based record with optional media/case study, not an imported Git repository. |
| Portfolio | One independently themed author-composed site, with private drafts and versioned public releases. |
| Template preset | Complete curated portfolio assembly from ordered sections and tokens; five initial, no fixed maximum. |
| Section layout | Reusable named-slot composition (L1–L8 initial); distinct from full preset. |
| Slot | Stable address in a section accepting typed components and props/content. |
| EMPTY | Slot without assigned implementation; recoverable content/source may remain in stash. |
| S0/S1/S2 | Pristine trusted component / owned-identical override / owned-modified override. |
| Unplaced | Protected tray of content/assets that could not map safely to changed layout/component. |
| Managed file | Closed-grammar project composition/content/theme file altered only via guarded operations. |
| Opaque owned code | User-owned TSX/JS/CSS not rewritten by visual structure operations. |
| Committed revision | Durable versioned project file-set head (not merely a text field buffer). |
| Local buffer | Uncommitted source/text; may be invalid but must be recoverable. |
| Last-good preview | Render of a prior valid revision, marked stale if current buffer invalid. |
| Author Preview | Draft view with safe authoring instrumentation. |
| Preview as Published | Pinned draft rendered under public static/security restrictions, not actually live. |
| Staging | Revision-pinned, read-only, token/expiry/revoke-controlled private review. |
| Public/Unlisted/Private | Visibility states: open indexed candidate / accessible with link / only owner, subject to delivery. |
| Release | Frozen immutable public output identified by hashes, pointer and visibility policy. |
| Live verified | Public visitor fetch confirms expected release; upload success alone is not sufficient. |
| Tombstone | Public route revoked/deleted response; must block direct bypass and account for caches. |
| DevScore | Private explainable category/conditional composite, no public ranking. |
| Source facts | Provider-specific public API data with time and origin, not proof of handle ownership. |
| 15-day Trash | Recovery interval for individually deleted projects/portfolios, not full-account erasure. |
| Qualified large tablet | Device/browser/input with verified full editor keyboard and interaction capability; phones excluded. |
| Glyph skeleton | Real loading text-shaped silhouettes, not conventional bars with decorative glyphs. |
| `[APPROVED]` | Explicit current owner decision. |
| `[PROOF]` | External technical/security/cost capability needs real tests. |
